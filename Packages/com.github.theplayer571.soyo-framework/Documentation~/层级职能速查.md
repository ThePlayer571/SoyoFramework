# 层级职能速查

## 整体介绍

- 后端：
    - Aggregate：存储全局数据；运算绝大部分游戏逻辑。
- 前端：
    - ViewController：将数据转换为表现；接受玩家输入。
- 通信方式：
    - Command：封装玩家输入，向 Aggregate 传递信息。
        - 方向：ViewController -> Aggregate
    - Event：事件机制，允许跨层级通信。
        - 方向：Aggregate -> ViewController, Aggregate -> Aggregate

## 具体介绍

### Aggregate - 聚合

- 职责：
    - 作为数据的容器，存放全局共享的数据
    - 处理游戏逻辑运算
- 设计追求：
    - 提供对外可读性良好的数据结构
    - 不暴露底层方法
    - 尽可能保持内部稳定运行
- 职能：
    - SendEvent、RegisterEvent
    - 与底层系统交互（如网络系统）

### ViewController - 表现控制器

- 职责：
    - 将数据转换为表现
    - 接受玩家输入
    - 及时处理无需进入后端的逻辑
- 设计追求：
    - 符合当前游戏审美
    - 尽可能处理错误输入
    - 不存在更高层，因此开发效率重要于代码整洁性
- 职能：
    - SendCommand
    - GetAggregateRoot (约定只读)
    - RegisterEvent
    - 操作View组件

### Command - 命令

- 职责：
  - 将输入转义为对后端的修改
  - 确保此次修改合法
- 设计追求：
  - 确保每次修改都安全
- 职能：
  - SendCommand
  - SendEvent
  - GetAggregateRoot
  - RegisterAggregateRoot, UnregisterAggregateRoot
